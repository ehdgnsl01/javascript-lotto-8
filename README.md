# javascript-lotto-precourse

## 1) 개요

- **목적**: 입력한 구입 금액만큼 로또를 발행하고, 당첨/보너스 번호와 비교해 **등수별 집계**와 **총 수익률**을 출력합니다.
- **규칙**

  - 번호 범위: **1~45** (정수)
  - 로또 1장: **중복 없는 6개**
  - 당첨 번호: **6개(중복X)** + **보너스 1개(당첨 6개와 중복X)**
  - 가격: **장당 1,000원**

- **등수/상금**

  - 1등: 6개 / 2,000,000,000원
  - 2등: 5개 + 보너스 / 30,000,000원
  - 3등: 5개 / 1,500,000원
  - 4등: 4개 / 50,000원
  - 5등: 3개 / 5,000원

## 2) 실행 방법

- **환경**: Node.js **22.19.0**
- **시작점**: `App.js`의 `run()`

```bash
# 테스트 실행
npm test

# 앱 실행 (프로젝트 스크립트에 따라)
npm start
```

## 3) 입출력 예시

**입력**

1. 구입금액(1,000원 단위)
2. 당첨 번호(`1,2,3,4,5,6`)
3. 보너스 번호(`7`)

**출력(예)**

```
8개를 구매했습니다.
[8, 21, 23, 41, 42, 43]
[3, 5, 11, 16, 32, 38]
[7, 11, 16, 35, 36, 44]
[1, 8, 11, 31, 41, 42]
[13, 14, 16, 38, 42, 45]
[7, 11, 30, 40, 42, 43]
[2, 13, 22, 32, 38, 45]
[1, 3, 5, 14, 22, 45]

당첨 통계
---
3개 일치 (5,000원) - 1개
4개 일치 (50,000원) - 0개
5개 일치 (1,500,000원) - 0개
5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
6개 일치 (2,000,000,000원) - 0개
총 수익률은 62.5%입니다.
```

## 4) 기능 목록

### A. 구입 금액 입력/검증

- [ ] 콘솔에서 구입 금액 입력
- [ ] **정수·양수·1,000원 단위** 검증

  - 예외: 0/음수/소수/1,000 배수 아님/숫자 아님 → `[ERROR] 구입 금액은 1,000원 단위의 양의 정수여야 합니다.`

- [ ] 유효 시 **발행 매수 = 금액 / 1000** 계산
- [ ] 에러 시 **금액 입력부터 재입력**

### B. 로또 발행/출력

- [ ] 발행 매수만큼 로또 생성 (각 장: **1~45 중복 없는 6개**)
- [ ] 각 장 번호 **오름차순 정렬** 출력
- [ ] 첫 줄 `N개를 구매했습니다.` 출력

### C. 당첨 번호 입력/검증

- [ ] `1,2,3,4,5,6` 형식 파싱(공백 제거 허용)
- [ ] **6개/정수/1~45/중복 없음** 검증

  - 예외: 개수≠6/범위 밖/숫자 아님/중복 →
    `[ERROR] 로또 번호는 1부터 45 사이의 숫자여야 합니다.` 또는
    `[ERROR] 번호는 중복될 수 없습니다.`

- [ ] 에러 시 **당첨 번호 입력부터 재입력**

### D. 보너스 번호 입력/검증

- [ ] 보너스 번호 1개 입력(정수/1~45)
- [ ] **당첨 6개와 중복 금지**

  - 예외: 범위 밖/숫자 아님 → 위 범위 에러 문구
  - 예외: 당첨 번호와 중복 → `[ERROR] 보너스 번호는 당첨 번호와 중복될 수 없습니다.`

- [ ] 에러 시 **보너스 번호만 재입력**

### E. 등수 판정/집계

- [ ] 각 로또의 **일치 개수** 계산 및 **보너스 일치 여부**
- [ ] 등수 규칙대로 집계 (1등:6 / 2등:5+보너스 / 3등:5 / 4등:4 / 5등:3)
- [ ] 등수별 **건수 합산**

### F. 수익률 계산/포맷

- [ ] **총 당첨금 = Σ(등수 건수 × 상금)**
- [ ] **수익률(%) = 총 당첨금 ÷ 구입 금액 × 100**
- [ ] **둘째 자리 반올림 → 소수 1자리** (예: `62.5%`)
- [ ] 금액 문자열 **천 단위 콤마**

### G. 결과 출력(형식 고정)

- [ ] 헤더:

  ```
  당첨 통계
  ---
  ```

- [ ] 출력 순서(고정):

  1. `3개 일치 (5,000원) - X개`
  2. `4개 일치 (50,000원) - X개`
  3. `5개 일치 (1,500,000원) - X개`
  4. `5개 일치, 보너스 볼 일치 (30,000,000원) - X개`
  5. `6개 일치 (2,000,000,000원) - X개`

- [ ] 마지막: `총 수익률은 {퍼센트}%입니다.`

## 5) 예외 정책

- 모든 에러 메시지는 **`[ERROR]`로 시작**합니다.
- 에러 발생 시 **해당 단계부터 재입력**합니다.
  (금액 에러 → 금액부터 / 당첨 번호 에러 → 당첨 번호부터 / 보너스 에러 → 보너스만)
- 대표 메시지

  - `[ERROR] 구입 금액은 1,000원 단위의 양의 정수여야 합니다.`
  - `[ERROR] 로또 번호는 1부터 45 사이의 숫자여야 합니다.`
  - `[ERROR] 번호는 중복될 수 없습니다.`
  - `[ERROR] 보너스 번호는 당첨 번호와 중복될 수 없습니다.`
